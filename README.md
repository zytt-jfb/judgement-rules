# 证件核验流水线 · vendor-cert-audit

把「一堆人的证件照片和扫描件」变成「一张能拿去整改的问题清单」。

核心不是 OCR 认字，而是拿**第三方权威数据**做交叉比对——只有权威源能回答「这张证是真的吗」「这张证是这个人的吗」。

> 本文所有姓名、身份证号、档案编码均为虚构示例，仅用于说明判定逻辑。

## 它能解决什么

- 几十到上千名持证人员的合规排查
- 判断：证件真伪 / 证件与人是否一致 / 是否过期 / 复审是否逾期 / 证类是否匹配岗位
- 已有同事的人工查验结果时，做交叉印证并找出双方漏项

## 两种用法

### 一、给 AI 用（技能包）

把 `skill/` 目录放到 `~/.workbuddy/skills/vendor-cert-audit/`，AI 会在相关任务中自动加载。

也可以直接调用其中的脚本：

```bash
pip install zxing-cpp pypdf pillow numpy openpyxl xlrd

# 批量解码证件二维码（大图自动切块，不要整图放大）
python skill/scripts/qr_decode.py --manifest manifest.jsonl --out qr.jsonl --workers 4

# 身份证合法性校验（GB 11643）
python skill/scripts/id_check.py 110101199002300012

# 判定 + 出表（一条命令跑完，判定口径全部固化在代码里）
python skill/scripts/judge_report.py \
    --verified official_verify.jsonl --staff roster.xls \
    --pidmap people.jsonl --manifest manifest.jsonl --qr qr.jsonl \
    --out 查验结果.xlsx
```

### 二、给不碰代码的人用（网页工具）

解压 `tool/`，双击 `启动工具.bat`，浏览器会自动打开：

1. 选人员名单（必填）
2. 选官方核验结果（可选）
3. 选附件清单（强烈建议，用于自动识别数据错位）
4. 点「生成核验报告」

数据全程在本机处理，不联网、不上传。

## 六段流水线

| 段 | 做什么 | 可复用性 |
|---|---|---|
| ① 会话接管 | CDP 复用已登录的浏览器，iframe 内定位 | 中 |
| ② 列表抓取 | 分页全量导出 | 中 |
| ③ 附件下载 | 页面内 fetch 取二进制 | 中 |
| ④ 内容解码 | PDF 文字层优先，二维码切块解码 | **高** |
| ⑤ 权威核验 | 用编号+签名换官方数据 | 中（平台相关） |
| ⑥ 判定出表 | 身份/证类/时效比对 + 按模板成表 | **高** |

其中 ④⑥ 完全通用，①③②⑤ 与具体业务系统相关，换系统需要重新逆向。

## 最值钱的部分：判定口径

`skill/references/judgement-rules.md` 里的八节规则，每一条都对应一次真实误判：

- **判「借证」前必须校验身份证号合法性**——实战中 21 条「不一致」里有 12 条其实是录入错误，不验号会把一半人冤枉成冒用
- **「我读不出二维码」不等于「证件有问题」**——曾有 41 人被误标，客户一对人工结果就穿帮
- **大图不要放大，要切块**——方向反了，还爆过两次内存
- **三个人格子指向同一个文件编号 = 数据串位**——658 人里 114 人被污染，最狠的一次把一张证算到了 7 个人头上
- **登高证不认「登高架设作业」**——架设是搭脚手架，与安装维护拆除是两个准操项目

## 边界

- **不包含任何业务系统的抓取实现**。①③②⑤ 需要按目标系统自行适配。
- **不做人脸比对**。证件照与本人是否一致，目前仍需人工目视。
- **不替代人工复核**。工具给的是线索和证据链，最终认定需要人判断。
